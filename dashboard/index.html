Sign in

This dashboard is signed out. There are two ways in, both starting somewhere else:

  1. From a paired device. Open Obsidian on a device that already syncs, go to the obsync plugin, and choose Open dashboard. It mints a one-time link that is valid for five minutes and signs this browser in.
  2. With the setup token. The server writes a setup token at first boot and that token stays valid. Open /login?token=<the token> on this host. This is the recovery path for a deployment with no working device, which is why the token is a standing credential and not a spent one.

The dashboard holds no vault key. It can never read a file, approve a device, or recover a vault; those all happen on a paired device.

Pairing

Pairing codes are minted on a device, never here. The dashboard holds no vault key, so it cannot approve a device: approval always happens in Obsidian on a device that already syncs.

  1. On a paired device, open the obsync plugin and choose Pair a new device. It shows one code, as text, as a copy button, and as a link. The code expires in 10 minutes.
  2. On the new device, install the plugin (see Install), open obsync, and paste the code.
  3. Back on the first device, approve <name> on <platform>. The vault key travels device to device, encrypted under a secret that never reaches the server.
  4. The new device starts syncing. It appears in Devices within a minute.

Install

Install Obsync inside Obsidian on each computer, phone, or tablet.

  1. Open your vault and go to Settings → Community plugins.
  2. Allow community plugins, select Browse, search for Obsync, then select Install and Enable.
  3. Open Obsync settings, enter your server's HTTPS address, and save the folders you want this device to sync.
  4. For your first device, complete First-time setup and keep the recovery phrase safe. For another device, use Pair a new device on a paired device, enter its pairing code here, then approve the new device there.

If Obsync is not in Browse, its directory listing is not yet available. Installation does not require copying plugin folders manually.

Updates

In Settings → Community plugins, select Check for updates and update Obsync. Your vault and pairing stay in place. Each device manages its own plugin updates.

Connection

Your server needs an HTTPS certificate your device trusts. If your server uses private connectivity, connect to that network before pairing or syncing. Certificate errors must be fixed by the server operator.
