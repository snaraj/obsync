Sign in

This dashboard is signed out. There are two ways in, both starting somewhere else:

  1. From a paired device. Open Obsidian on a device that already syncs, go to the obsync plugin, and choose Open dashboard. It mints a one-time link that is valid for five minutes and signs this browser in.
  2. With the setup token. The server prints a one-time setup token on its first boot. Open /login?token=<the token> on this host. This is the recovery path for a deployment with no working device.

The dashboard holds no vault key. It can never read a file, approve a device, or recover a vault; those all happen on a paired device.

Pairing

Pairing codes are minted on a device, never here. The dashboard holds no vault key, so it cannot approve a device: approval always happens in Obsidian on a device that already syncs.

  1. On a paired device, open the obsync plugin and choose Pair a new device. It shows one code, as text, as a copy button, and as a link. The code expires in 10 minutes.
  2. On the new device, install the plugin (see Install), open obsync, and paste the code.
  3. Back on the first device, approve <name> on <platform>. The vault key travels device to device, encrypted under a secret that never reaches the server.
  4. The new device starts syncing. It appears in Devices within a minute.

Escrow a domain key

Read this before you use the form. Escrow hands the server a domain's key. From that moment the server can decrypt every file in that folder and serve it as plaintext to any signed-in dashboard user and to any mount that asks. This is the one place where the blind-server property is deliberately given up, and it stays given up for that folder until the key is revoked. A stolen disk plus an escrowed key is a readable vault. Escrow a domain only when a workload on this server genuinely has to read it, and never the domain that covers the whole vault.

Install

The first install on a device is manual by design, and so is every update: the plugin tells you when this server runs a newer version, and you install the matching GitHub Release the same way. Community-plugin restricted mode must be off in Obsidian.

Files

Steps

Put all three files in <vault>/.obsidian/plugins/obsync/.

macOS, Windows, Linux

  1. Download the three files above.
  2. In Finder or Explorer, open the vault folder, then .obsidian, then plugins. Create a folder called obsync if it is not there.
  3. Copy the three files in.
  4. In Obsidian: Settings → Community plugins → enable obsync.

iOS and iPadOS

  1. Download the three files in Safari; they land in Files.
  2. Files → On My iPhone (or iPad) → Obsidian → your vault → .obsidian (hidden folders are visible in Files) → plugins → create obsync.
  3. Paste the three files in, then restart Obsidian and enable the plugin.

Android

  1. Download the three files.
  2. With any file manager, open the vault folder and use the same .obsidian/plugins/obsync/ layout.
  3. Restart Obsidian and enable the plugin.

Then open the plugin, paste a pairing code from an already-paired device, and approve it there. A brand-new vault instead runs setup with the server's setup token.
