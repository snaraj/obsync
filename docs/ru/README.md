# Self Hosted Private Sync

Самостоятельно размещаемая живая синхронизация со сквозным шифрованием для
[Obsidian](https://obsidian.md). Ваши заметки синхронизируются через сервер,
который вы запускаете сами. Заметки, вложения и имена файлов шифруются на
вашем устройстве, и сервер никогда не получает ключ. Плагин работает на
каждой платформе, где работает Obsidian, на компьютере и на телефоне. Нет ни
подписки, ни учётной записи где-либо ещё.

**Что-то не работает? → [Устранение неполадок](https://snaraj.github.io/obsync/troubleshooting/) (на английском)**

## Установка

![Настройки плагина открываются разделом Get started: строка Setup guide с кнопкой Open the guide, над полем Server URL](../assets/settings-get-started.png)

Установите плагин через **Настройки → Сторонние плагины → Обзор**. Найдите
**Self Hosted Private Sync** (идентификатор плагина `obsync-private-sync`).
Нужен Obsidian 1.13.0 или новее. Настройки плагина открываются руководством по
настройке: до него одно нажатие.

> [!IMPORTANT]
> - Он синхронизируется с сервером, который запускаете **вы**: ни размещённого сервиса, ни учётной записи где-либо ещё.
> - Сначала сделайте резервную копию хранилища; держите фразу восстановления из 24 слов не на том устройстве, которое её создало.
> - Никогда не запускайте его рядом с другой синхронизацией (Obsidian Sync, облачная папка, другой плагин) на одном хранилище.
> - Молодая программа: прочитайте запись [`CHANGELOG.md`](../../CHANGELOG.md) о вашей версии, обновите каждое устройство и знайте, что охватил каждый [прогон проверки](../validation-runs/).

## Начать синхронизацию

Самый короткий полный путь — Compose с Caddy в вашей собственной сети, из
клона этого репозитория. Он даёт HTTPS в любой сети, без домена и без учётной
записи где-либо. [Одна сеть, шаг за шагом](../same-network.md) проводит по нему
с каждым экраном. Замените `vX.Y.Z` ниже на устанавливаемый выпуск — самый
новый тег на [странице Releases](https://github.com/snaraj/obsync/releases/latest).

**1. Проверьте образ.** Затем запускайте ровно тот дайджест, который вывела
проверка:

```sh
cosign verify ghcr.io/snaraj/obsync:vX.Y.Z \
  --certificate-identity https://github.com/snaraj/obsync/.github/workflows/release-publisher.yml@refs/heads/main \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

**2. Запустите сервер:**

```sh
OBSYNC_IMAGE=ghcr.io/snaraj/obsync@sha256:<digest> \
  OBSYNC_HOST=sync.example.org \
  OBSYNC_BIND_ADDRESS=192.168.1.10 \
  docker compose -f deploy/compose/docker-compose.yml up -d
```

`OBSYNC_HOST` — это имя, которое будут вводить ваши устройства. Оно должно
разрешаться только в вашей собственной сети. `OBSYNC_BIND_ADDRESS` — адрес, на
котором публикуются порты 80 и 443: адрес привязки ограничивает интерфейс
назначения, а не источник, поэтому кто до него доберётся, решает ваш
файрвол. Compose не запустится, пока вы не сделаете выбор.

**3. Прочитайте токен первичной настройки.** При первом запуске сервер
выпускает токен первичной настройки и записывает его в свой том журнала, с
режимом 0600, и никогда не пишет его в лог. Он один раз создаёт вашу учётную запись и
остаётся резервным способом входа в панель. Берегите его так же, как фразу
восстановления:

```sh
docker exec obsync-obsync-1 obsyncd setup-token
```

```sh
docker cp obsync-obsync-1:/data/journal/v1/setup-token - | tar -xO
```

**4. Настройте каждое устройство.** Один раз доверьтесь сертификату сервера
([как](../server.md#trust-the-certificate-authority-once-per-device)).
Установите плагин и следуйте [Быстрому старту](../quickstart.md): настройте
первое устройство, затем подключите остальные.

Перед сервером уже стоит HTTPS от прокси или туннеля, которому вы доверяете?
Тогда запустите [голый сервер](../server.md#already-have-a-tls-terminator-docker).

## К чему этот плагин получает доступ

- **Ваш сервер и ничего больше.** Каждый запрос идёт на **Server URL**, который вы вводите; ни телеметрии, ни третьих сторон.
- **Учётная запись на этом сервере**, созданная из токена первичной настройки; ваша учётная запись Obsidian здесь ни при чём.
- **GitHub Releases, через Obsidian**, для установки и обновления; дополнительные файлы выпуска Obsidian игнорирует.
- **Список файлов вашего хранилища**, чтобы решить, что синхронизировать; скрытые папки (`.obsidian`, `.git`) и папки-симлинки пропускаются.
- **Буфер обмена: только запись** кнопками **Copy code** и **Copy link** в **Pair a new device**, никогда не чтение.
- **Ваш браузер, когда вы просите руководство по настройке.** Руководство проекта открывается в нём; сам плагин ничего не отправляет.

Что сервер может видеть и чего не может: [`SECURITY.md`](../../SECURITY.md) и [модель угроз](../threat-model.md).

## Версии

LATEST — это самый новый тег на
[странице Releases](https://github.com/snaraj/obsync/releases/latest). Именно
его Obsidian устанавливает и до него обновляет. `main` — это EDGE: влитая, но
ещё не выпущенная работа, для тех, кто собирает из исходников. Бета-канала и
предварительных тегов нет. Раздел Unreleased в журнале изменений — запись
того, что есть в EDGE.
