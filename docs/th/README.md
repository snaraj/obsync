# Self Hosted Private Sync

การซิงก์สดแบบโฮสต์เอง เข้ารหัสจากต้นทางถึงปลายทาง สำหรับ [Obsidian](https://obsidian.md) โน้ตของคุณซิงก์ผ่านเซิร์ฟเวอร์ที่คุณรันเอง โน้ต ไฟล์แนบ และชื่อไฟล์ถูกเข้ารหัสบนอุปกรณ์ของคุณ และเซิร์ฟเวอร์ไม่เคยได้รับกุญแจ ปลั๊กอินทำงานได้บนทุกแพลตฟอร์มที่ Obsidian ทำงาน ทั้งเดสก์ท็อปและมือถือ ไม่มีการสมัครสมาชิก และไม่มีบัญชีกับใครที่อื่น

## การติดตั้ง

![การตั้งค่าของปลั๊กอินที่เปิดขึ้นมาพร้อม Get started: แถว Setup guide และปุ่ม Open the guide ของแถวนั้น อยู่เหนือช่อง Server URL](../assets/settings-get-started.png)

ติดตั้งปลั๊กอินจาก **การตั้งค่า → ปลั๊กอินโดยชุมชน → เลือกดู** ค้นหา **Self Hosted Private Sync** (ไอดีปลั๊กอิน `obsync-private-sync`) ต้องใช้ Obsidian 1.13.0 ขึ้นไป การตั้งค่าของปลั๊กอินเปิดขึ้นมาพร้อมคู่มือการตั้งค่า ซึ่งเปิดได้ด้วยการกดครั้งเดียว

> [!IMPORTANT]
> - ปลั๊กอินนี้ซิงก์ไปยังเซิร์ฟเวอร์ที่ **คุณ** รันเอง ไม่มีบริการแบบโฮสต์ให้ และไม่มีบัญชีกับใครที่อื่น
> - สำรองข้อมูลห้องนิรภัยของคุณก่อน และเก็บวลีกู้คืน 24 คำไว้นอกอุปกรณ์ที่สร้างมันขึ้นมา
> - อย่ารันมันควบคู่กับการซิงก์อื่น (Obsidian Sync โฟลเดอร์คลาวด์ หรือปลั๊กอินตัวอื่น) บนห้องนิรภัยเดียวกันเป็นอันขาด
> - ซอฟต์แวร์ที่ยังใหม่: อ่านรายการใน [`CHANGELOG.md`](../../CHANGELOG.md) ของเวอร์ชันที่คุณใช้อยู่ อัปเดตอุปกรณ์ทุกเครื่อง และรู้ว่า[การทดสอบด้วยอุปกรณ์จริง](../validation-runs/)แต่ละครั้งครอบคลุมอะไรบ้าง

## เริ่มซิงก์

เส้นทางที่ครบถ้วนและสั้นที่สุดคือ Compose พร้อม Caddy บนเครือข่ายของคุณเอง จากการเช็กเอาต์รีโพซิทอรีนี้ วิธีนี้ให้ HTTPS บนเครือข่ายใดก็ได้ โดยไม่ต้องมีโดเมน และไม่ต้องมีบัญชีกับใครทั้งสิ้น [เครือข่ายเดียวกัน ทีละขั้นตอน](../same-network.md)พาคุณผ่านเส้นทางนี้พร้อมทุกหน้าจอ แทนที่ `vX.Y.Z` ด้านล่างด้วยรุ่นที่คุณกำลังติดตั้ง ซึ่งก็คือแท็กล่าสุดบน[หน้า Releases](https://github.com/snaraj/obsync/releases/latest)

**1. ตรวจสอบอิมเมจ** จากนั้นรัน digest ที่การตรวจสอบพิมพ์ออกมาให้ตรงทุกตัวอักษร:

```sh
cosign verify ghcr.io/snaraj/obsync:vX.Y.Z \
  --certificate-identity https://github.com/snaraj/obsync/.github/workflows/release-publisher.yml@refs/heads/main \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

**2. เริ่มเซิร์ฟเวอร์:**

```sh
OBSYNC_IMAGE=ghcr.io/snaraj/obsync@sha256:<digest> \
  OBSYNC_HOST=sync.example.org \
  OBSYNC_BIND_ADDRESS=192.168.1.10 \
  docker compose -f deploy/compose/docker-compose.yml up -d
```

`OBSYNC_HOST` คือชื่อที่อุปกรณ์ของคุณจะพิมพ์ ชื่อนี้แค่ต้องแปลงเป็นที่อยู่ได้บนเครือข่ายของคุณเองก็พอ ส่วน `OBSYNC_BIND_ADDRESS` คือที่อยู่ที่พอร์ต 80 และ 443 ถูกเปิดให้เข้าถึง: ที่อยู่สำหรับ bind จำกัดอินเทอร์เฟซปลายทาง ไม่ใช่ต้นทาง ดังนั้นไฟร์วอลล์ของคุณคือสิ่งที่ตัดสินว่าใครเข้าถึงได้ Compose จะไม่ยอมเริ่มทำงานจนกว่าคุณจะเลือก

**3. อ่านโทเค็นตั้งค่า** เมื่อบูตครั้งแรก เซิร์ฟเวอร์จะสร้างโทเค็นตั้งค่าและเขียนลงโวลุ่ม journal ของมันด้วยโหมด 0600 โดยไม่เคยบันทึกลงล็อก โทเค็นนี้สร้างบัญชีของคุณหนึ่งครั้ง และยังคงเป็นช่องทางเข้าสู่ระบบเพื่อกู้คืนของแดชบอร์ดต่อไป เก็บรักษามันให้ดีเท่ากับวลีกู้คืน:

```sh
docker cp obsync-obsync-1:/data/journal/v1/setup-token - | tar -xO
```

**4. ตั้งค่าอุปกรณ์แต่ละเครื่อง** เชื่อถือใบรับรองของเซิร์ฟเวอร์หนึ่งครั้ง ([วิธีทำ](../server.md#trust-the-certificate-authority-once-per-device)) ติดตั้งปลั๊กอิน แล้วทำตาม[เริ่มต้นอย่างรวดเร็ว](../quickstart.md): ตั้งค่าอุปกรณ์เครื่องแรก แล้วจับคู่เครื่องอื่น ๆ

มี HTTPS อยู่ด้านหน้าอยู่แล้ว จากพร็อกซีหรืออุโมงค์ที่คุณเชื่อถือใช่ไหม ให้รัน[เซิร์ฟเวอร์เปล่า ๆ](../server.md#already-have-a-tls-terminator-docker)แทน

## สิ่งที่ปลั๊กอินนี้เข้าถึง

- **เซิร์ฟเวอร์ของคุณ ไม่มีที่อื่น** ทุกคำขอไปยัง **Server URL** ที่คุณพิมพ์ ไม่มีเทเลเมทรี ไม่มีบุคคลที่สาม
- **บัญชีบนเซิร์ฟเวอร์นั้น** ซึ่งสร้างขึ้นจากโทเค็นตั้งค่า บัญชี Obsidian ของคุณไม่มีส่วนเกี่ยวข้องใด ๆ
- **GitHub Releases ผ่าน Obsidian** สำหรับการติดตั้งและการอัปเดต Obsidian ไม่สนใจไฟล์แนบอื่น ๆ ของรุ่น
- **รายการไฟล์ในห้องนิรภัยของคุณ** เพื่อตัดสินว่าจะซิงก์อะไร โฟลเดอร์ที่ซ่อนไว้ (`.obsidian`, `.git`) และโฟลเดอร์ที่เป็นซิมลิงก์จะถูกข้ามไป
- **คลิปบอร์ด ซึ่งถูกเขียนเท่านั้น** โดย **Copy code** และ **Copy link** ใน **Pair a new device** ไม่เคยถูกอ่าน
- **เบราว์เซอร์ของคุณ เมื่อคุณขอเปิดคู่มือการตั้งค่า** คู่มือของโปรเจกต์จะเปิดขึ้นที่นั่น ตัวปลั๊กอินเองไม่ได้ส่งอะไรออกไป

สิ่งที่เซิร์ฟเวอร์มองเห็นได้และมองไม่เห็น: [`SECURITY.md`](../../SECURITY.md) และ[โมเดลภัยคุกคาม](../threat-model.md)
