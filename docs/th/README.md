# Self Hosted Private Sync

การซิงก์สดแบบโฮสต์เอง เข้ารหัสจากต้นทางถึงปลายทาง สำหรับ [Obsidian](https://obsidian.md): เซิร์ฟเวอร์ Rust ตัวเดียวที่ไม่ต้องพึ่งดีเพนเดนซีใด ๆ พร้อมแดชบอร์ดในตัว ซึ่งคุณรันเอง บวกกับปลั๊กอินตัวนี้ ไฟล์ขนาดใดก็ได้ ทุกแพลตฟอร์มของ Obsidian ไม่มีการสมัครสมาชิก ไม่มีบุคคลที่สาม

ติดตั้งจาก การตั้งค่า → ปลั๊กอินโดยชุมชน → เลือกดู โดยค้นหาชื่อ **Self Hosted Private Sync** (ไอดีปลั๊กอิน `obsync-private-sync`) บน Obsidian 1.13.0 ขึ้นไป

**เพิ่งเริ่มใช้? เริ่มจาก[คู่มือการตั้งค่า](https://snaraj.github.io/obsync/setup/) (ภาษาอังกฤษ)** ช่วยให้คุณเลือกวิธีที่อุปกรณ์เข้าถึงเซิร์ฟเวอร์ของคุณ และอธิบายแต่ละวิธีทีละขั้นตอน ใน Obsidian: การตั้งค่า → Self Hosted Private Sync → Setup guide

> [!IMPORTANT]
> - ปลั๊กอินนี้ซิงก์ไปยังเซิร์ฟเวอร์ที่ **คุณ** รันเอง ไม่มีบริการแบบโฮสต์ให้ และไม่มีบัญชีกับใครที่อื่น
> - สำรองข้อมูลห้องนิรภัยของคุณก่อน และเก็บวลีกู้คืน 24 คำไว้นอกอุปกรณ์ที่สร้างมันขึ้นมา
> - อย่ารันมันควบคู่กับการซิงก์อื่น (Obsidian Sync โฟลเดอร์คลาวด์ หรือปลั๊กอินตัวอื่น) บนห้องนิรภัยเดียวกันเป็นอันขาด
> - ซอฟต์แวร์ที่ยังใหม่: อ่านรายการใน [`CHANGELOG.md`](../../CHANGELOG.md) ของเวอร์ชันที่คุณใช้อยู่ อัปเดตอุปกรณ์ทุกเครื่อง และรู้ว่า[การทดสอบด้วยอุปกรณ์จริง](../validation-runs/)แต่ละครั้งครอบคลุมอะไรบ้าง

## สิ่งที่ปลั๊กอินนี้เข้าถึง

- **เซิร์ฟเวอร์ของคุณ ไม่มีที่อื่น** ทุกคำขอไปยัง **Server URL** ที่คุณพิมพ์ ไม่มีเทเลเมทรี ไม่มีบุคคลที่สาม
- **บัญชีบนเซิร์ฟเวอร์นั้น** ซึ่งสร้างขึ้นจากโทเค็นตั้งค่า บัญชี Obsidian ของคุณไม่มีส่วนเกี่ยวข้องใด ๆ
- **GitHub Releases ผ่าน Obsidian** สำหรับการติดตั้งและการอัปเดต Obsidian ไม่สนใจไฟล์แนบอื่น ๆ ของรุ่น
- **รายการไฟล์ในห้องนิรภัยของคุณ** เพื่อตัดสินว่าจะซิงก์อะไร โฟลเดอร์ที่ซ่อนไว้ (`.obsidian`, `.git`) และโฟลเดอร์ที่เป็นซิมลิงก์จะถูกข้ามไป
- **คลิปบอร์ด ซึ่งถูกเขียนเท่านั้น** โดย **Copy code** และ **Copy link** ใน **Pair a new device** ไม่เคยถูกอ่าน

สิ่งที่เซิร์ฟเวอร์มองเห็นได้และมองไม่เห็น: [`SECURITY.md`](../../SECURITY.md) และ[โมเดลภัยคุกคาม](../threat-model.md)

## เริ่มซิงก์

ห้าขั้นตอน จากที่ยังไม่มีอะไรเลย ไปสู่อุปกรณ์สองเครื่องที่ซิงก์ตรงกัน `v1.0.6` คือรุ่นที่หน้านี้เขียนขึ้นโดยอ้างอิง ให้ใช้แท็กของรุ่นที่คุณกำลังติดตั้ง

### 1. เริ่มเซิร์ฟเวอร์

ตรวจสอบลายเซ็น แล้วรัน digest ที่มันพิมพ์ออกมานั้นให้ตรงกันเป๊ะ ๆ:

```sh
cosign verify ghcr.io/snaraj/obsync:v1.0.6 \
  --certificate-identity https://github.com/snaraj/obsync/.github/workflows/release-publisher.yml@refs/heads/main \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

เส้นทางที่ง่ายที่สุดคือ Compose พร้อม Caddy จากการเช็กเอาต์รีโพซิทอรีนี้: HTTPS บนเครือข่ายใดก็ได้ ไม่ต้องมีโดเมน และไม่ต้องมีบัญชีกับใครทั้งสิ้น

```sh
OBSYNC_IMAGE=ghcr.io/snaraj/obsync@sha256:<digest> \
  OBSYNC_HOST=sync.example.org \
  OBSYNC_BIND_ADDRESS=192.168.1.10 \
  docker compose -f deploy/compose/docker-compose.yml up -d
```

`OBSYNC_HOST` คือชื่อที่อุปกรณ์ของคุณจะพิมพ์ มันแค่ต้องแปลงชื่อได้บนเครือข่ายของคุณเองก็พอ ส่วน `OBSYNC_BIND_ADDRESS` คือที่อยู่ที่พอร์ต 80 และ 443 ถูกเผยแพร่อยู่: ที่อยู่สำหรับ bind จำกัดอินเทอร์เฟซปลายทาง ไม่ใช่ต้นทาง ดังนั้นไฟร์วอลล์ของคุณคือสิ่งที่ตัดสินว่าใครเข้าถึงมันได้ Compose จะไม่ยอมเริ่มทำงานจนกว่าคุณจะเลือก

มี HTTPS อยู่ด้านหน้าอยู่แล้ว ไม่ว่าจะจากพร็อกซีหรืออุโมงค์ที่คุณเชื่อถือใช่ไหม ให้รันเซิร์ฟเวอร์เปล่า ๆ แทน: [การรันเซิร์ฟเวอร์](../server.md)

### 2. อ่านโทเค็นตั้งค่า

เมื่อบูตครั้งแรก เซิร์ฟเวอร์จะสร้างโทเค็นตั้งค่าขึ้นมาและเขียนลงบนโวลุ่มเจอร์นัลของมัน โหมด 0600 และไม่เคยถูกบันทึกลงล็อก โทเค็นนี้สร้างบัญชีของคุณหนึ่งครั้ง และยังคงเป็นวิธีเข้าสู่ระบบสำหรับกู้คืนของแดชบอร์ดต่อไป: เก็บรักษามันด้วยความระมัดระวังเท่ากับวลีกู้คืน อ่านมันจากตัวคอนเทนเนอร์:

```sh
docker cp obsync-obsync-1:/data/journal/v1/setup-token - | tar -xO
```

### 3. เชื่อถือใบรับรอง หนึ่งครั้งต่ออุปกรณ์หนึ่งเครื่อง

Caddy ลงลายเซ็นด้วยผู้ออกใบรับรองที่มันสร้างขึ้นเองตอนเริ่มทำงานครั้งแรก อุปกรณ์แต่ละเครื่องจึงต้องเชื่อถือผู้ออกใบรับรองนั้นหนึ่งครั้ง ส่งออกใบรับรองรากแล้วติดตั้งมันตามแต่ละแพลตฟอร์ม ดังที่[การรันเซิร์ฟเวอร์](../server.md#trust-the-certificate-authority-once-per-device)แสดงไว้ บน iOS การเชื่อถือใบรับรองเป็นสวิตช์ที่สองหลังจากติดตั้งมันแล้ว

### 4. ตั้งค่าอุปกรณ์เครื่องแรก

1. การตั้งค่า → ปลั๊กอินโดยชุมชน → เลือกดู → **Self Hosted Private Sync** → ติดตั้ง → เปิดใช้งาน
2. ตั้ง **Server URL** ให้เป็นเซิร์ฟเวอร์ของคุณ (`https://sync.example.org` พร้อมพอร์ตเมื่อมันไม่ใช่ 443) แล้วเลือก **Whole vault** หรือ **Selected folders only** ซึ่งภายหลังจะแคบลงได้เท่านั้น

   ![แท็บการตั้งค่าของปลั๊กอิน: ช่อง Server URL ที่บรรจุชื่อโฮสต์สำหรับสาธิต กล่องส่วนหัวของ edge และแถว Connection พร้อมปุ่ม Check และ Open dashboard ของมัน](../assets/settings-server.png)

3. วางโทเค็นตั้งค่าใต้ **First-time setup** เลือก **Set up** แล้วจดวลีกู้คืน 24 คำไว้

   ![ส่วน This device ของแท็บการตั้งค่า: แถว Pairing พร้อม Pair this device และ Pair a new device, แถว First-time setup พร้อมช่อง Setup token และปุ่ม Set up รวมถึงแถว Vault key](../assets/settings-setup.png)

### 5. จับคู่อุปกรณ์เครื่องที่สอง

1. ติดตั้งปลั๊กอินบนเครื่องนั้นด้วย **Server URL** เดียวกัน จากนั้นบนอุปกรณ์เครื่องแรกให้เรียก **Pair a new device** เพื่อรับรหัสที่ใช้ได้นานสิบนาที

   ![กล่องโต้ตอบ Pair a new device บนอุปกรณ์เครื่องแรก โดยรหัสของมันถูกปิดบังไว้ พร้อมปุ่ม Copy code และ Copy link และบรรทัด Waiting for the new device](../assets/pair-new-device.png)

2. บนอุปกรณ์เครื่องที่สอง ให้เปิด **Pair this device** วางรหัสลงไป แล้วเลือก **Pair**
3. กลับมาที่อุปกรณ์เครื่องแรก ให้อนุมัติมันตามชื่อ แก้ไขโน้ตบนเครื่องใดก็ได้ในสองเครื่องนั้น แล้วมันจะไปปรากฏบนอีกเครื่องภายในไม่กี่วินาที

   ![อุปกรณ์เครื่องแรกถามว่าจะอนุมัติอุปกรณ์เครื่องใหม่ตามชื่อของมันหรือไม่ พร้อมปุ่ม Approve และ Reject](../assets/pair-approve.png)

![ภาพเคลื่อนไหว: รหัสจับคู่ถูกแสดงบนอุปกรณ์เครื่องแรก ถูกวางลงบนเครื่องที่สอง ได้รับการอนุมัติบนเครื่องแรก และโน้ตแรกเดินทางไปถึงเครื่องที่สอง](../assets/pairing.gif)

กำลังลองบนคอมพิวเตอร์เครื่องเดียวอยู่ใช่ไหม `http://127.0.0.1:8080` เข้าถึงเซิร์ฟเวอร์เปล่าได้บนคอมพิวเตอร์ ส่วน Obsidian บน iOS และ Android ปฏิเสธ HTTP ธรรมดา

ภาพหน้าจอจากโทรศัพท์ยังไม่อยู่ในรีโพซิทอรีนี้ ภาพเหล่านั้นถ่ายบนอุปกรณ์ของผู้ดูแลเอง และจะถูกเพิ่มเข้ามาเมื่อการทดสอบครั้งหนึ่งบันทึกมันไว้

ทุกขั้นตอนแบบเต็ม: [เริ่มต้นอย่างรวดเร็ว](../quickstart.md)

## ขั้นสูง: Cloudflare

การติดตั้งอ้างอิงไม่มีชื่อโฮสต์สาธารณะ: Cloudflare Tunnel และเส้นทางส่วนตัวเข้าถึงเครือข่ายของเซิร์ฟเวอร์ และไคลเอนต์ Cloudflare One บนอุปกรณ์แต่ละเครื่องนำ Server URL ไปถึงที่นั่น ส่วนชื่อโฮสต์สาธารณะที่อยู่หลัง Cloudflare Access พร้อมโทเค็นบริการใน **Edge service-token headers** และ `OBSYNC_EDGE=cloudflare` ก็ใช้ได้เช่นกัน ทั้งสองแบบ ทีละขั้นตอน: [Cloudflare](cloudflare.md)

## วิธีอื่นในการเข้าถึงเซิร์ฟเวอร์ของคุณ

ไม่ว่าคุณจะเลือกแบบไหน ปลั๊กอินต้องการ HTTPS พร้อมใบรับรองที่อุปกรณ์ทุกเครื่องเชื่อถือ ส่วนตัวเซิร์ฟเวอร์เองยังคงอยู่บน HTTP ธรรมดาหลังจุดสิ้นสุด TLS นั้น

- **LAN เท่านั้น** เส้นทาง Compose ข้างต้น เข้าถึงได้เฉพาะที่บ้าน ไม่มีการซิงก์เมื่ออยู่นอกบ้าน
- **WireGuard** VPN ของคุณเองที่ย้อนกลับเข้าสู่เครือข่ายของคุณ: เร็วที่สุดและเป็นของคุณทั้งหมด ต้องมีการตั้งค่าเพียร์บนอุปกรณ์ทุกเครื่อง
- **Tailscale** เมช WireGuard แบบมีผู้ดูแล: ตั้งค่าน้อยที่สุด แต่มีบุคคลที่สามคอยประสานมัน ภายใต้เงื่อนไขของแพ็กเกจนั้น
- **reverse proxy ที่ทำ TLS อัตโนมัติ** เช่น Caddy บนชื่อสาธารณะ: เข้าถึงได้จากอินเทอร์เน็ต และเป็นหน้าที่ของคุณที่ต้องคอยแพตช์มัน
- **Cloudflare Tunnel** ตามข้างต้น ไม่มีพอร์ตขาเข้า แต่มีผู้ให้บริการอยู่บนเส้นทาง ภายใต้เงื่อนไขของเขา

สิ่งที่อุปกรณ์ซึ่งเดินทางไปไหนมาไหนต้องมี (เส้นทาง ชื่อ ใบรับรอง ไฟร์วอลล์ และคำขออนุญาตเครือข่ายท้องถิ่นของ iOS): [การเข้าถึงจากนอก LAN ของคุณ](../server.md#reaching-it-from-outside-your-lan)

## การแก้ปัญหา

| อาการ | สาเหตุที่น่าจะเป็น | สิ่งแรกที่ควรลอง |
| --- | --- | --- |
| `obsync: offline` | อุปกรณ์เข้าถึง Server URL ไม่ได้ | เปิด URL นั้นในเบราว์เซอร์บนอุปกรณ์เครื่องนั้น แล้วตรวจสอบพอร์ต HTTPS และเส้นทาง |
| โทรศัพท์เชื่อมต่อไม่ได้ ขณะที่คอมพิวเตอร์ซิงก์อยู่ | ใบรับรองส่วนตัวไม่ได้รับความเชื่อถือบนโทรศัพท์ | ติดตั้งใบรับรองราก และบน iOS ให้เปิดใช้งานมันใต้ "Certificate Trust Settings" ด้วย |
| `401 stale_timestamp` | นาฬิกาคลาดเคลื่อนเกิน 300 วินาที | เปิดการตั้งเวลาอัตโนมัติ บนอุปกรณ์หรือบนเซิร์ฟเวอร์ |
| `403 device_pending` | ยังไม่มีใครอนุมัติอุปกรณ์เครื่องนี้ | อนุมัติมันตามชื่อบนอุปกรณ์ที่คุณจับคู่มา |
| ไฟล์ไม่เคยมาถึง | มันอยู่นอกโฟลเดอร์ที่เลือกไว้ หรือใหญ่เกินเพดานขนาดของโทรศัพท์ | ตรวจสอบ **Sync folders on this device** และบนโทรศัพท์ให้เรียก **Show remote-only files** |

อาการอื่นทุกอย่าง รหัสข้อผิดพลาดทุกรหัส และวิธีรายงานมัน: [การแก้ปัญหา](../troubleshooting.md)
