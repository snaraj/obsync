# Saved-editor candidate, 2026-10-06

This candidate separates recent-input attribution, confirmed native saving,
publication batching and incoming-write safety. The paired desktop campaign, Windows durability repair and physical-phone
journeys below bind different explicit checkpoints. The final preview-event
delta has desktop evidence; final mobile and hosted checks are recorded
separately before author completion.

## Reproduction and scope

two fresh native profiles and synthetic vaults. The server and plugin retained
end-to-end encryption, authenticated requests and durable writes. Transport

profiles used the explicit mock-keychain testing mode, so they do not establish

The experimental launcher takes an explicit built source and a new external

```sh
OBSYNC_LATENCY_CADENCE_MS=50 OBSYNC_LATENCY_CHARACTERS=180 \
```

## Windows durability follow-up

The native Windows journey and Windows plugin tests at `0f7fcf7` failed with
`EPERM` at the final file flush. The host had reopened the public editor's
saved file read-only. Windows requires write access for
[FlushFileBuffers](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-flushfilebuffers).
The repair opens the already confined file with nontruncating `r+`; descriptor,
path and parent identity checks and mandatory fsync remain in place.
The queued native-host fixture now requires that writable existing-file mode
on every platform. Its editor clock also advances explicitly: a slow disk
must not make a test's deliberately unsaved input save before the assertion.
After refusal, the test advances saving and verifies the local input survives.

The repaired native-host suite passed 84/84. Six targeted mutations were
detected, including read-only final flush, missing fsync, missing public save,
missing adapter queue, changed expected bytes and stale view binding. The
full repair gate passed: 2,055 plugin tests, 83 dashboard tests, 873 repository
contracts, 94.72% Rust line coverage, CLI/chart checks and both secret scans.
At `ba55aad2c23fb2e93d5ddbb77ded4d2c613931fc`, native Windows, macOS,
and both Linux keychain configurations passed in workflow run `37533826821`.
The Windows plugin suite exposed a separate observer defect: its final-file
hook compared native backslash paths with a slash-separated vault path and
therefore never recorded the successful flush. The hook now normalizes the
suffix with the host's path implementation; the mandatory post-save fsync
and writable-handle assertions are unchanged. The corrected native-host
suite passed 84/84 locally. At `955d19db`, hosted Windows plugin tests and
native Obsidian on Windows, macOS and both Linux keyring modes passed.
The separate CLI workflow hit its unchanged five-second helper deadline
during replacement installation (run `37536764431`, job `112519660311`,
5,010 ms). The preceding seven CLI runs passed and no CLI implementation or
journey changed from the immediately preceding passing head. This establishes
an intermittent bounded refusal, not its environmental cause. The failure is
retained; no timeout, custody check or automatic retry was added.
