# 1.1.11 and 1.1.12: an iPhone the encryption upgrade removed pairs again, 2026-11-02

The phone journey 1.1.11 and 1.1.12 owed by the owner's decision in
[release trains](../release-trains.md). These were the owner's devices and
vault: one iPhone with the official Obsidian app, and one macOS desktop with
Obsidian 1.14.5. Both updated through Community plugins. The server was the
owner's own deployment of the published release. Before this run, the phone
held notes the desktop also held, under an older key from before the
encryption upgrade, and the server had removed it.

## 1.1.11

| Step | Result |
| --- | --- |
| Update | The phone took 1.1.11 from Community plugins. It said it was not paired yet and how to pair. |
| Pair again | The desktop chose **Pair a new device**. The code moved by copy and paste, and both prompts showed the same six digits. The desktop approved. |
| Fail | Before keeping the key, the phone asked to upload "149 notes the server's vault does not" hold. Every one of them was on the server, at the same path and with the same bytes. **Cancel** uploaded nothing, and the claimed credential revoked itself. The server answered the phone's one feed read with an empty page whose cursor was short of the head (#376). |

## 1.1.12

| Step | Result |
| --- | --- |
| Update | The phone and the desktop took 1.1.12 from Community plugins. The desktop's plugin files match the release's digests; `main.js` is the release's plus the line Obsidian appends on install. |
| Pair | The same steps, with matching codes, approved. There was no upload question. The phone said it was paired and its first sync was running. |
| Pass | The phone went from 149 files in 15 folders to 151 files in 16 folders, the desktop's counts. It gained the one note and the one folder it lacked. The desktop's **Force sync** then answered "in step with the server: checked 151 files here and 365 on the server; sent 0, received 0". The server listing count was unchanged from before the pairing, and no conflict copy was observed on the desktop. |

## Desktop, before the pairing (1.1.11)

The desktop's first **Force sync** received 2 folder records. They re-cased a
top-level folder to the spelling the removed phone had last published. The
folder was renamed back in Obsidian, and later presses answered "sent 1",
then "sent 0, received 0". A stale child-folder record left by the re-case is
#375.
