# WHY A FILE OF ITS OWN. AGENTS.md requirement 5 keeps the product
# dependency-free: the Rust workspace is the standard library, the plugin has
# no runtime dependency, and the dashboard is hand-written. MkDocs is not a
# product input. It is CI TOOLING, like cosign, helm and gitleaks, it ships
# nothing into the binary, the chart or the plugin bundle, and every page it
# renders is a Markdown file a reader can open in this repository without it.
#
# WHY EVERY TRANSITIVE DEPENDENCY IS LISTED. The install command is
#
#     python3 -m pip install --no-deps --only-binary=:all: -r docs/requirements.txt
#
# `--no-deps` means pip installs exactly the lines below and resolves nothing,
# so a new release of a dependency of a dependency cannot enter a build; the
# closure is therefore written out in full rather than left to a resolver.
# `--only-binary=:all:` refuses source distributions, so no package's own
# build code runs here. Adding, removing or moving a line is a reviewed edit.
#
